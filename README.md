# Imran Saleem — Resume Website

Professional responsive resume website made with HTML, CSS and JavaScript, based on the supplied resume.

## Features
- Animated hero introduction and JavaScript typing effect
- Scroll-triggered content reveals using IntersectionObserver
- Scroll reading-progress indicator
- Active navigation section highlighting
- Hover micro-interactions on cards, buttons and skills
- Dark/light theme toggle with saved preference
- Responsive mobile navigation
- Reduced-motion accessibility support

## Preview
Open `index.html` in any modern browser. No build tools or dependencies are required.

## Publish with GitHub Pages
1. Create a public GitHub repository, e.g. `imran-resume`.
2. Upload `index.html`, `style.css`, and `script.js` into the repository root.
3. Open **Settings → Pages**, choose **Deploy from a branch**, **main**, and **/(root)**, then save.
4. After deployment, open the website URL shown in Pages settings.
5. Take screenshots and add them with your repository and live URLs to your Web Engineering assignment Word document.

The Types of Work section summarizes experience in the resume and does not claim independent named portfolio projects.
